# Contributing

Thanks for your interest in Sagrada! This is a personal fork with a deliberately small scope. Bug reports and small, focused fixes are welcome; please open an issue before starting larger changes or new features.

Use [this repository’s issues](https://github.com/sebastianstoecklin/Sagrada/issues) for Sagrada-specific problems. Include your macOS version, `sagrada --version`, and steps to reproduce. Only report upstream after reproducing on an AeroSpace build.

For pull requests, briefly explain the change, follow the existing style, and run `./test.sh` (or note what you couldn’t test). See the [development notes](dev-docs/development.md) for setup.

Please preserve existing license and copyright notices. Contributions use the applicable project license: [MIT](LICENSE.txt) for Sagrada, [GPLv3](vendor/JankyBorders/LICENSE) for the vendored helper.
