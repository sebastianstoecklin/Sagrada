# Sagrada 0.4.3

## Keep dialogs out of tiling

- Explicitly modal windows now float, even when they report a standard window role and an enabled fullscreen button. This improves detection of native print, open, and save dialogs, including in apps with special window heuristics.
- Attached sheets are left to macOS instead of having their geometry managed by Sagrada.
- Ordinary non-modal windows continue to tile. Existing configuration is not overwritten.

## Verification

421 automated tests passed, including new coverage for modal windows, non-modal windows, and attached sheets. Live print/file dialogs still require manual verification in individual apps.

## Installation

Download and extract **Sagrada-v0.4.3.zip**, quit Sagrada, and replace the app in Applications. The ZIP includes the universal app and CLI, configuration examples, documentation, licenses, and matching source/build script for the separately bundled JankyBorders helper.

Requires macOS 13+; workspace indicators and JankyBorders require macOS 14+. Apple Silicon and Intel are supported. This build is ad-hoc signed, not notarized. macOS may require renewed Accessibility approval after replacement.

Verify the archive with `shasum -a 256 -c Sagrada-v0.4.3.zip.sha256`.
