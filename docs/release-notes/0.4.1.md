# Sagrada 0.4.1

## Icon and packaging

- Add a native macOS Icon Composer icon to avoid the gray compatibility enclosure around the padded legacy artwork. The stained-glass design is retained, with a full-bleed image for modern macOS and legacy assets for older systems.
- Include Sagrada and third-party license notices inside `Sagrada.app/Contents/Resources/legal/`, so they remain with the installed app.
- Document JankyBorders' GPLv3 license, dated local modifications, and how to rebuild the matching helper source included in every release ZIP.
- Set and verify consistent app and CLI release versions.

## Repository maintenance

- Simplify the README and contribution guidelines; downloads now use a version-independent release link.
- Remove unused upstream moderation workflows, IDE files, and an unused icon.
- Track new source files normally while ignoring build products and local caches.
- Exclude Finder metadata from release ZIPs and include example configuration, helper, release notes, and SHA-256 checksum.

No configuration migration is required. Existing configuration is not overwritten.

## Installation

Download and extract **Sagrada-v0.4.1.zip**, quit Sagrada, and replace the app in Applications. The ZIP includes the universal app and CLI, configuration examples, licenses, and matching source/build script for the separately bundled JankyBorders helper.

Requires macOS 13+; workspace indicators and JankyBorders require macOS 14+. Apple Silicon and Intel are supported. This build is ad-hoc signed, not notarized. macOS may require renewed Accessibility or Input Monitoring approval after replacement.
