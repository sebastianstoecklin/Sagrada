# Sagrada 0.6 — Floating window arrangement

Floating workspaces now combine free placement with keyboard-driven snapping:

- Cmd–Control–U/I/J/K: upper-left, upper-right, lower-left, lower-right quadrants.
- Cmd–Control–F/G/H: left, center, right thirds.
- Cmd–Control–arrows: halves.
- Cmd–Control–Enter: maximize in the usable screen area, respecting outer gaps.
- Cmd–Control–C: center; + / -: grow / shrink by 40 points per dimension, centered and bounded by the screen. Applications may enforce larger minimum sizes.
- Cmd–Control–Space: toggle the whole workspace between Tiling and Floating. Cmd–Option–F remains the per-window toggle.

The native `sagrada float-window ACTION` command refuses tiled workspaces and native minimized/fullscreen windows. No external snapping utility or helper script is required.

Bundled JankyBorders excludes windows belonging to Floating workspaces. Other displays' tiled workspaces keep their borders; returning to Tiling or moving windows updates exclusions automatically. A small Sagrada-specific IPC extension in the bundled helper maintains exclusions for newly discovered windows too.

## Configuration migration

App updates preserve existing TOML. Copy the new Floating keybindings from `docs/config-examples/default-config.toml`, replacing the old Cmd–Control–Left/Right join bindings. Join now uses Cmd–Option–arrows in all four directions; Swap remains on Cmd–Shift–arrows. The workspace toggle changes from Cmd–Option–Shift–F to Cmd–Control–Space. Service-mode joins remain unchanged. Borders require no new user setting.

## Download and installation

Download `Sagrada-v0.6.0.zip`, quit Sagrada and replace the app in Applications. The archive includes the universal Apple Silicon/Intel app and CLI, configuration, documentation, licenses, and the matching source/build script for the separately bundled GPLv3 JankyBorders helper.

Verify the archive with `shasum -a 256 -c Sagrada-v0.6.0.zip.sha256`.

The build is ad-hoc signed, not notarized. macOS may require renewed **Accessibility** approval after replacement. Interactive workspace indicators require macOS 14.4+; JankyBorders requires macOS 14+; the app supports macOS 13+.

The bundled shortcuts are global while Sagrada runs. Floating actions do nothing in Tiling workspaces but still reserve their keys. Cmd–Control–Space normally opens the macOS character viewer; choose a different binding if you need that system shortcut. Existing Cmd-based navigation and launch shortcuts can also replace familiar macOS/app actions.
