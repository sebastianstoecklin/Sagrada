# Sagrada 0.5.6

## Advanced workspace indicators

- Compact Circled Numbers indicators: occupied workspace numbers are bold, empty ones light. Only the focused workspace has an outline: a circle for Floating, a subtly rounded rectangle for Tiling.
- Centered digits, 22-point cells and 3-point spacing. Active outlines have a 19-point outer size and a stronger 1.5-point stroke.
- Left-click a workspace to select it. Click the active workspace to toggle Tiling / Floating. Right-click (or Control-click) anywhere on the strip to open the Sagrada dropdown; no separate logo is needed.
- Workspaces 1–5 stay available and visible even when empty. Version-2 configs can override the default with an explicit `persistent-workspaces` list. Other workspaces appear as they are used.

## Native workspace layouts

- Choose **Workspaces → workspace → Tiling / Floating** in the dropdown, including for inactive or empty workspaces.
- Layout choices persist by workspace name across restarts. New workspaces default to Tiling; new windows inherit the workspace mode.
- Switching modes converts existing managed windows. Native fullscreen, minimized and hidden windows are left alone until restored. Tiling still permits dialogs and explicit per-window floating.
- CLI: `sagrada layout --root floating tiling` toggles the focused workspace. Use `--workspace NAME --root tiling` or `--workspace NAME --root floating` to set another workspace.
- The bundled Cmd–Option–Shift–F shortcut now uses the native toggle.

## Stability

- Native status-button click handling accounts for screen/window coordinates and image scaling, rather than relying on custom child views in the macOS menu-bar host.
- Rapid/multiple-click protection prevents overlapping layout toggles.
- Plain AppKit dropdown avoids the NSHostingMenu crash seen during local development. Closing status-item host windows no longer terminates the background app.
- 439 automated tests cover layouts, click-coordinate conversion, outlines, glyph centering, menu rebuilding and existing functionality.

## Updating from 0.4.5

Your configuration is not overwritten. If it calls the old `workspace-layout.sh`, remove its `on-window-detected` callback and change its toggle binding to `layout --root floating tiling`, or install the updated compatibility wrapper from `config/`. Old helper marker files are no longer used.

Interactive indicators require macOS 14.4 or newer. Earlier macOS versions retain the menu-only fallback (macOS 13 uses plain text). The app supports Apple Silicon and Intel; JankyBorders requires macOS 14+.

Download and extract **Sagrada-v0.5.6.zip**, quit Sagrada, and replace the app in Applications. The archive includes the universal app and CLI, configuration examples, documentation, licenses, and matching source/build script for the separately bundled JankyBorders helper. Sagrada is MIT-licensed; JankyBorders is GPLv3-licensed.

This build is ad-hoc signed, not notarized. macOS may require renewed **Accessibility** approval after replacement.

Verify the archive with `shasum -a 256 -c Sagrada-v0.5.6.zip.sha256`.
