# Sagrada 0.4.0

## Scroll Reverser

Reverse classic mouse-wheel scrolling directly in Sagrada, without changing macOS's Natural Scrolling preference or running another helper.

- **Opt-in:** disabled by default for new and existing configurations.
- **Menu controls:** Scroll Reverser → Enabled, Reverse Vertical, and Reverse Horizontal. Vertical reversal defaults to on, horizontal reversal to off.
- **Gesture passthrough:** continuous scrolling, gesture phases, and momentum events are not modified, preserving normal trackpad and Magic Mouse scrolling.
- **Permission guidance:** if the event tap cannot start, the submenu offers Grant Permissions / Retry and a link to Input Monitoring settings. Check Accessibility and, if requested by macOS, Input Monitoring for Sagrada; retry or restart after granting access.
- **Clean lifecycle:** disabling the feature, turning off both axes, or quitting Sagrada removes the event filter.

## Configuration

Menu changes are session-only; a config reload or app restart restores TOML settings. To persist your choice, add this top-level table to `~/.sagrada.toml` and reload:

```toml
[scroll-reverser]
enabled = true
reverse-vertical = true
reverse-horizontal = false
```

Existing configuration files are never overwritten. No changes are required if you do not want scroll reversal.

## Device limitations

The filter identifies **discrete wheel events**, not specific physical devices. Some smooth-scrolling mice and drivers emit continuous events and will not be reversed. Touch input converted into discrete wheel events cannot be distinguished reliably. Avoid running another scroll-reversal tool at the same time.

## Download and installation

Download **Sagrada-v0.4.0.zip**, extract it, quit Sagrada, and move **Sagrada.app** into Applications. The ZIP also includes the CLI, example configuration, workspace-layout helper, licenses, and corresponding source for the bundled JankyBorders helper.

Universal build for **Apple Silicon and Intel**. Requires **macOS 13+**; integrated JankyBorders and workspace indicators require **macOS 14+**. The app is ad-hoc signed, not Apple-notarized. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway only if you trust the download. Replacing an ad-hoc signed build may require renewing Accessibility/Input Monitoring approval.
