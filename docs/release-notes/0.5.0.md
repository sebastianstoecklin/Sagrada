# Sagrada 0.5.0

- Refined Circled Numbers indicators: active Floating uses a circle; active Tiling uses a subtly rounded rectangle. Only the focused workspace has a frame. Occupied workspace names are bold, empty ones light. Only existing workspaces appear, without placeholder gaps.
- Workspaces menu: switch focus and select Tiling or Floating independently for each workspace, even when inactive or empty.
- Workspace mode is saved in Sagrada preferences across restarts. Switching converts existing managed windows; new windows inherit the mode. Native fullscreen, minimized and hidden windows stay in their native containers until restored. Dialogs and explicit per-window floating remain supported in Tiling.
- CLI: `sagrada layout --root floating tiling`; target another workspace with `--workspace NAME`. The bundled Cmd–Option–Shift–F shortcut now uses this native toggle.
- Legacy `workspace-layout.sh` is a compatibility wrapper. Existing configs should remove its detection callback and use the native toggle, or install the updated wrapper. Old helper marker files are no longer used.

macOS 14 or newer is required for graphical menu-bar indicators; macOS 13 retains its text fallback. This local build is ad-hoc signed, so Accessibility approval may need renewing after installation.
