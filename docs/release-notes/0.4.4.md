# Sagrada 0.4.4

## Workspace indicators and menu cleanup

- Ordered workspace indicators now include configured persistent workspaces, even when empty and not visible. The bundled default config keeps workspaces 1–5 persistent.
- The menu bar consistently uses the ordered i3-style display; the experimental Appearance selector has been removed.
- Open Config and Reload Config are grouped in a Config submenu.
- In the bundled config, Command–Shift–Minus selects the tiles layout and cycles orientation; Command–Option–Minus shrinks a tile. Shortcut documentation reflects these changes.

Existing user configuration is not overwritten. To adopt the new defaults, update your config explicitly; add `persistent-workspaces = ['1', '2', '3', '4', '5']` before any table headers if desired.

## Verification

421 automated tests passed, including the bundled persistent-workspace configuration check. Menu appearance still requires manual verification.

## Installation

Download and extract **Sagrada-v0.4.4.zip**, quit Sagrada, and replace the app in Applications. The ZIP includes the universal app and CLI, configuration examples, documentation, licenses, and matching source/build script for the separately bundled JankyBorders helper.

Requires macOS 13+; workspace indicators and JankyBorders require macOS 14+. Apple Silicon and Intel are supported. This build is ad-hoc signed, not notarized. macOS may require renewed Accessibility approval after replacement.

Verify the archive with `shasum -a 256 -c Sagrada-v0.4.4.zip.sha256`.
