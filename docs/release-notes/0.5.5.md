# Sagrada 0.5.5

- Route compact workspace-strip clicks through the native NSStatusBarButton instead of custom child buttons. Child-button unit tests did not cover macOS menu-bar host event forwarding.
- Map the current screen mouse position into the status button's own window and actual image rectangle. Do not use locationInWindow from the forwarded event, which can belong to another host window.
- Account for image padding and scaling; clicks outside a workspace cell are no-ops, never menu fallbacks.
- Remove the separate logo. Right-click (or Control-click) the workspace strip to open the native dropdown. Left-click misses never open it.
- New workspaces default to Tiling, independent of the focused workspace's mode. Saved per-workspace choices remain persistent.
- Retain compact spacing, centered digits, and rapid-click/startup protections.
- Replace obsolete child-button tests with image-mapping and screen-to-window conversion tests, including scaled images and negative monitor coordinates.

Local ad-hoc signed updates may require renewed Accessibility approval. Automated geometry tests are not a substitute for a real menu-bar click test after approval.
