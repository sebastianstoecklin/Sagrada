# Sagrada 0.5.3

- Fix startup termination reproduced in LLDB: replacing the permission status item closed the last host window, triggering NSApplication's terminate-after-last-window-closed path. The application delegate now explicitly keeps the background app alive, and replacement status items are created before old ones are removed.
- Remove NSHostingMenu from interactive workspace indicators. Crash reports identified an AttributeGraph precondition failure in NSHostingMenu.rootView.setter. The dropdown is now a plain AppKit NSMenu, including all workspace, config and desktop-helper actions.
- Retain menu action targets beyond menu tracking; defer detaching the menu until tracking unwinds.
- Add repeated menu-construction tests across permission states.

Ad-hoc signed local builds can require renewed Accessibility approval.
