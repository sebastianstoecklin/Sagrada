# Sagrada 0.4.2

## Screenshots without workspace shortcut collisions

While Sagrada runs:

- **Option–Shift–3** captures the entire screen.
- **Option–Shift–4** captures a selection or window (press Space to select a window).
- **Option–Shift–5** opens macOS screenshot and recording controls.
- The new **Screenshots** submenu offers all three actions without memorizing shortcuts.

Captures use macOS's configured destination. The bundled Command–Shift–3/4/5 bindings remain workspace-move commands, without also invoking screenshots when the temporary override succeeds. The screenshot shortcuts stay available in main and service mode. Touch Bar capture is not changed.

## Behavior and limitations

- Original macOS screenshot hotkeys, including their Control-to-clipboard variants, are temporarily disabled. Their previous enabled states are restored on normal quit; saved keyboard preferences are not edited.
- The override uses dynamically loaded private WindowServer APIs. If unavailable, the Screenshots menu reports the error and the original system shortcuts remain active. Screenshot and workspace actions can then run in parallel.
- Option–Shift–3/4/5 replace the characters those keys normally type. Custom Sagrada bindings and other utilities should not use those combinations.
- Force-quitting or a crash may skip restoration. Logging out and back in restores the saved system configuration.
- The README now explains the remap, permissions, and cleanup behavior. A separate shortcut overview documents other macOS/app overlaps.

No configuration migration is required. Existing configuration is not overwritten.

## Installation

Download and extract **Sagrada-v0.4.2.zip**, quit Sagrada, and replace the app in Applications. The ZIP includes the universal app and CLI, configuration examples, release documentation, licenses, and matching source/build script for the separately bundled JankyBorders helper.

Requires macOS 13+; workspace indicators and JankyBorders require macOS 14+. Apple Silicon and Intel are supported. This build is ad-hoc signed, not notarized. After replacement, macOS may require renewed Accessibility approval (toggle Sagrada off/on in System Settings), Input Monitoring approval, or screen-capture permission.
