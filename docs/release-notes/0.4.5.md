# Sagrada 0.4.5

## Compact menu

- The dropdown header shows Sagrada and the running build's version.
- Shorter submenu labels: Config → Open… / Reload, and compact screenshot capture actions.
- Caffeinate is now **Keep awake**, with Off, System, and System & display modes.
- Scroll Reverser is now **Reverse scrolling**, with Enabled, Vertical, and Horizontal controls.
- The README includes a desktop screenshot showing tiled windows, borders, and workspace indicators.

No configuration migration is required. Existing configuration is not overwritten; the `[scroll-reverser]` configuration keys are unchanged.

## Installation

Download and extract **Sagrada-v0.4.5.zip**, quit Sagrada, and replace the app in Applications. The ZIP includes the universal app and CLI, configuration examples, documentation, licenses, and matching source/build script for the separately bundled JankyBorders helper.

Requires macOS 13+; workspace indicators and JankyBorders require macOS 14+. Apple Silicon and Intel are supported. This build is ad-hoc signed, not notarized. macOS may require renewed Accessibility approval after replacement.

Verify the archive with `shasum -a 256 -c Sagrada-v0.4.5.zip.sha256`.
