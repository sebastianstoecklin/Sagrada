# Sagrada 0.5.2

- Replace the single image-based workspace click target with one native NSStatusItem button per workspace. Sender identity now chooses the workspace; forwarded event coordinates, Retina scaling and image padding cannot affect selection.
- A left-click on a workspace cannot fall through to opening the dropdown. Right-click/Control-click opens a native status-item menu with AppKit-managed placement and tracking.
- Guard against menu re-entry and avoid replacing menu-hosting buttons during menu tracking.
- Serialize workspace click operations. Ignore double/multiple-click follow-ups and rapid repeats instead of queueing unexpected toggles; recover from cancellation/errors without terminating the app.
- Query mouse-only event properties only for mouse events; menu-bar host forwarding can supply other event types.
- Regression tests exercise real NSControl target/action dispatch for each workspace and busy/double/multiple-click suppression, in addition to layout and digit-centering tests.

The macOS log for the reported disappearance contained normal menu-driven termination rather than a crash report. Version 0.5.1 could fall through to the dropdown when coordinate hit testing failed. This release removes that fallback and the manual popup positioning.

As with previous local ad-hoc signed builds, macOS may require renewed Accessibility approval after installation.
