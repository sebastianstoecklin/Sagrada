# Sagrada 0.6.1

- **Native screenshots:** The Screenshots menu and existing Option–Shift–3/4/5 aliases invoke the enabled screenshot shortcuts configured in macOS. macOS handles capture and the save destination. Sagrada no longer needs Screen Recording permission for screenshots; forwarding still uses its existing Accessibility permission.
- **No shortcut changes:** Sagrada no longer disables macOS screenshot shortcuts. Workspace bindings are unchanged, so standard macOS screenshot shortcuts can overlap with the bundled Cmd–Shift–3/4/5 workspace bindings. If they clash, use non-conflicting macOS screenshot shortcuts or adjust your Sagrada configuration.
- **Scroll reversal defaults on:** Vertical reversal for classic mouse wheels is enabled by default. Horizontal reversal remains off, continuous trackpad gestures are unaffected, and an explicit `[scroll-reverser]` `enabled = false` still opts out.

Download `Sagrada-v0.6.1.zip` for Apple Silicon and Intel. Quit Sagrada before replacing the app. Your configuration is preserved. This build is ad-hoc signed, not notarized; macOS may ask you to renew Accessibility approval. Verify the ZIP with `shasum -a 256 -c Sagrada-v0.6.1.zip.sha256`.
