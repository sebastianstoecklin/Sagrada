# Sagrada 0.5.4

- Compact shared workspace strip: 22-point native buttons with 3-point gaps, matching the original contiguous indicator spacing.
- Separate Sagrada app-logo status item opens the native dropdown on left-click. Right-clicks on workspaces do nothing.
- Left-click still selects a workspace, or toggles Tiling/Floating when it is already focused. Sender-based actions, multi-click protection and glyph centering are retained.
- Remove the five persistent default workspaces. Only occupied, visible or focused workspaces are displayed; empty persistent placeholders are not shown.
- Keep the logo and workspace status hosts alive across model updates. Retain the application delegate's last-window-close protection and plain AppKit dropdown from 0.5.3.
- Test actual child-button hit testing and action dispatch within the shared host.

Local ad-hoc signed updates may require renewed Accessibility approval.
